# Community Bench Rosters

Share a bench. Borrow one.

Each file here is a JSON bench roster: a named set of judges with temperaments, ready to drop into any VJS repo.

## Format

```json
{
  "name": "Roster name",
  "description": "What this bench is for",
  "judges": [
    {
      "name": "Judge Name",
      "temperament": "One-line judicial lens"
    }
  ]
}
```

## Submitting a bench

Open a PR with your roster file. The clerk will review for:
- Valid JSON
- At least 5 judges (for a full Supreme Council sitting)
- No names that land on living or sitting real-world jurists

*Names are inventions adjacent to the giants of the bench, never real sitting or living jurists.*
