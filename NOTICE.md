## Working alongside other code

Keep this source separate from differently licensed third-party code, and prefer a
clean-room recreation to importing incompatible source. A noncommercial term cannot
lawfully be laid over code you received under a licence that permits commercial use, and
it cannot be laundered off this code by co-residence either: see REG-BUNDLE-001(4) and
[2026] VJS-PC 22, which holds that a noncommercial component leaks a **prohibition on the
commercial use the consuming licence expressly grants** - a contradiction no downstream
consumer can cure by disclosing anything.
