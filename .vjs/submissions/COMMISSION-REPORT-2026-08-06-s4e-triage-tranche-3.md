## Systemic findings routed onward

1. THREE MISSING KERNEL CONCEPTS block whole clusters at once: a matter/convene
   entity (most of the s6 stay rows), a sensitivity rating on verbs (the
   trust-boundary and verb/capability carve-outs), and a reservation/review-date
   registry (tolling, s11). Building any one flips several court-enforced rows to
   gateable in one stroke.
2. UNPROVEN, NOT UNBUILT: invariants the kernel already loads and runs
   (INV-NO-V1-GAP-FILLER, INV-ENTRENCHED-GATE-001, the incorporation substring
   check) have no teeth test; the predicate_teeth pattern closes this class cheaply.
   The same applies to by-construction facts never pinned by a regression test (the
   Gazette-output-is-inert loader property, the v1-resolver exclusion, ancestry
   independence, the container-independence of the enforcement hook, the
   no-signing-key manifest shape, ministry-path absence).
3. A LIVE CONTRADICTION: choose_court routes constitutional-prefix issues to the
   Supreme Court while ACT-002 s3's token demands the Privy Council; the row needs a
   text reconciliation or a distinguishing tag before any registry entry.
4. THE PERMIT CLOSE GAP: an Active permit past its work has zero consequence
   (REG-004 close_permit, bypass_lifecycle_step) - a PERMIT-NOT-CLOSED staged finding
   is the cheap cure.
5. THE INVARIANT BYPASS: a plain vjs validate or an empty-changeset run skips the
   entire default invariant suite; run it unconditionally.
6. CHEAP WARRANT-GATE EXTENSIONS, same file, several rows each: expiry parsing (then
   the 90-day cap, automatic lift on expiry, no-extension-by-inaction, and the lapse
   cross-reference), jurisdiction singularity, schedule-form checks, and a digest
   drift check for the fresh-warrant rule.
7. Approval self-decision: ApprovalQueue::decide takes a bare decider string with
   nothing stopping the acting agent approving itself (ACT-001 s5) - flagged for the
   human-checkpoint build.
