# Private Working Area

This directory is the canonical superrepo-private working area.

It exists so agents have a standard place to put unredacted local evidence, repo-level facts, client/project identifiers, operational notes, screenshots, logs, and private routing papers that must not enter the public/system-data record.

Contents are ignored by git. Only this README and the directory `.gitignore` are tracked so every clone has the same functional empty private area.

Use this for:

- unredacted evidence behind a redacted court or policy filing;
- repo-level formation audits before redaction;
- private ministry working papers;
- local identifiers needed during analysis but not suitable for the central Judicature or Legislature record;
- temporary sweep outputs that may include private facts.

Do not use this for:

- binding law;
- judgments;
- statutory instruments;
- public policy briefings;
- citator rows;
- durable public system-data records.

Public files may refer to this area only generically, for example: "unredacted evidence is retained in the superrepo private working area." They should not expose private filenames or contents unless redacted and lawful.
